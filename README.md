# РИСУЕМ

Рисовалка и раскраска для ребёнка четырёх лет. Android, Kotlin, Jetpack Compose.
Полностью офлайн: ни интернета, ни рекламы, ни покупок, ни аналитики.
**Ноль разрешений в манифесте.**

Герои те же, что в игре «МУРКА и КРЯ»: КИРА, МАМА, ПАПА и звери —
КРЯ, ЁЖИК, ЛИСА, МИШКА, ВОЛК, ЛЕВ.

## Как установить с телефона

1. Откройте [Releases](../../releases) — верхняя сборка самая свежая.
2. Нажмите на файл `risuem-НОМЕР.apk` — он скачается одним касанием.
3. Откройте скачанный файл. Android спросит разрешение устанавливать
   приложения из этого источника — разрешите.
4. Иконка «РИСУЕМ» появится на рабочем столе.

## Что внутри

Два режима, выбор двумя большими иконками на старте.

**КРАСИМ.** Сетка картинок с крупными превью: герои, звери, ДОМИК, МАШИНА,
СОЛНЦЕ, ЦВЕТОК, РЫБКА, БАБОЧКА, ЁЛКА, ТОРТ. Тап по области — она заливается
выбранным цветом, краска растекается от пальца за 250 мс. Снизу палитра из
двенадцати кругов, выбранный пульсирует. НАЗАД отменяет последнюю заливку,
ЕЩЁ РАЗ стирает всё (удержание секунду, с кольцом), ГОТОВО сохраняет.
Закрасили всё — конфетти и «Как красиво!».

**РИСУЕМ.** Чистый лист. Толстая кисть, тонкая кисть, ластик, палитра,
наклейки, корзина. Линия плавная, толщина зависит от скорости — получается
фломастер, а не проволока. Наклейки приземляются с отскоком, двигаются
пальцем, растягиваются двумя, выбрасываются в корзину. НАЗАД отменяет
последний штрих, помнит двадцать шагов.

**РАБОТЫ.** Сохранённые рисунки. Тап — открыть и продолжить, удержание
полторы секунды — удалить (с кольцом). В углу каждой работы две маленькие
кнопки для взрослого: отдать картинку другому приложению и сохранить файлом
системным диалогом.

**Новый герой** (для взрослого). Вход: удержать замок полторы секунды,
потом ответить на пример вида 7 × 8. Дальше — фото из галереи системным
Photo Picker или снимок камерой, приложение само убирает однотонный фон,
делает раскраску с крупными областями, показывает результат и даёт переснять.
Имя заглавными, не длиннее семи букв — это единственное поле ввода
во всём приложении.

Выход из приложения — только удержание домика полторы секунды.
Системная кнопка «назад» приложение не закрывает.

## Как всё устроено

```
core/   чистый Kotlin без Android, покрыт тестами:
        заливка области, стек отмены, фото → раскраска, модель документа
app/    экраны на Compose, растровые холсты, звук и голос
tools/  make_sounds.py — генератор звуков, make_faces.py — вырезание лиц
art/    исходные фотографии героев
```

Тесты математики: `./gradlew :core:test` — 59 проверок.

## Что менять, если захочется другого

| Хочу | Файл | Что сделать |
| --- | --- | --- |
| Другие цвета палитры | `app/src/main/java/com/dobdmitry/risuem/ui/Theme.kt` | список `PaintColors` — двенадцать цветов, порядок как в радуге |
| Другие шаблоны раскрасок | `app/src/main/java/com/dobdmitry/risuem/art/Figures.kt` | добавьте `Figure` из частей и впишите его в `TEMPLATES` |
| Новый герой из фотографии | прямо в приложении | замок → пример → ФОТО или СНЯТЬ |
| Другие лица героев | `art/*.jpg` + `tools/make_faces.py` | перезапустите скрипт, он положит новые `face_*.png` |
| Другие звуки | `tools/make_sounds.py` | правьте параметры и запустите: `python3 tools/make_sounds.py` |
| Другие надписи и голос | `app/src/main/java/com/dobdmitry/risuem/ui/Words.kt` | не длиннее семи букв, заглавными, «ё» именно «ё» |
| Толщина кистей | `app/src/main/java/com/dobdmitry/risuem/ui/DrawScreen.kt` | `WIDTH_BRUSH`, `WIDTH_THIN`, `WIDTH_ERASER` |
| Крупность областей раскраски | `app/src/main/java/com/dobdmitry/risuem/art/Templates.kt` | `MIN_REGION` — чем больше, тем крупнее области |
